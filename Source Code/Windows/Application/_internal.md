# Packaged Windows runtime

Download [AXOVRIM_Windows_internal.zip](https://github.com/ArviZuko/Axovrim-Toolkit-Inspector/releases/download/large-assets-2026-10-19/AXOVRIM_Windows_internal.zip) from the [AXOVRIM large downloads release](https://github.com/ArviZuko/Axovrim-Toolkit-Inspector/releases/tag/large-assets-2026-10-19).

Extract the archive into this `Application` directory. It contains the `_internal` folder required by the bundled `AXOVRIM.exe`; keep `_internal` beside the executable. The archive is a generated Windows runtime and is distributed separately because it includes files larger than GitHub's regular Git file limit. Alternatively, use the Windows installer or build from `Source Code/Windows/SRC/`.
