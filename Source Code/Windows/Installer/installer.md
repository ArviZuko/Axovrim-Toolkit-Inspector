# Windows installer

Download [AXOVRIM_Setup.exe](https://github.com/ArviZuko/Axovrim-Toolkit-Inspector/releases/download/large-assets-2026-10-19/AXOVRIM_Setup.exe) from the [AXOVRIM large downloads release](https://github.com/ArviZuko/Axovrim-Toolkit-Inspector/releases/tag/large-assets-2026-10-19).

The installer executable is 264 MB and is distributed as a Release asset rather than a regular Git file. `AXOVRIM_Setup.iss` is the Inno Setup source used to build it. Use the installer on a supported 64-bit Windows system, with the RealSense camera and USB 3 connection described in the project README.
