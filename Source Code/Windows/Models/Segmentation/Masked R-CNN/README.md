# Mask R-CNN experiment

Download [maskrcnn_roboflow_weights.pth](https://github.com/ArviZuko/Axovrim-Toolkit-Inspector/releases/download/large-assets-2026-10-19/maskrcnn_roboflow_weights.pth) from the [AXOVRIM large downloads release](https://github.com/ArviZuko/Axovrim-Toolkit-Inspector/releases/tag/large-assets-2026-10-19) and place it in this folder beside `IS_3000_Masked_Rcnn.ipynb`.

The weight file is about 170 MB and is provided as a Release asset because it exceeds GitHub's regular Git file limit. This folder is a segmentation experiment; the deployed application uses its separately supplied YOLO weight.
